Mini_CTorch

From-scratch tensor operations, CUDA matrix multiplication kernels, automatic differentiation and neural-network training.

C · CUDA · GPU kernels · Autograd

Source repository

Implementation

Implements CPU and CUDA tensor primitives, a graph-based backward pass, fully connected layers, a mean squared error loss and CUDA SGD updates. The matrix multiplication CUDA implementation uses a 16 × 16 thread-block mapping with dedicated backward kernels.

Model training

Example experiment

A configurable 1 → 8 → 8 → 1 network with tanh activations learns a sampled sine function with mean squared error and stochastic gradient descent.
