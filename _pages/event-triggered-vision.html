A webcam perception prototype that investigates when changes in a scene should trigger vision-language reasoning.

Live webcam demo

The problem

A visual assistant does not necessarily need to run an expensive vision-language model on every camera frame. I explored an event-triggered approach in which a lighter visual representation monitors changes and routes relevant input to a local vision-language model.

Prototype

  1. Separate scene regions. A webcam frame is divided into person and background views using MediaPipe segmentation.
  2. Measure visual change. CLIP encodes the full frame and the two region views. Cosine distances are compared with earlier embeddings.
  3. Resolve a change. In the live demo, a trigger compares the full-frame CLIP embedding with previous description embeddings. A match can be reused; otherwise, LLaVA describes the full frame. The original command-line prototype can instead route the selected region to LLaVA.

Engineering focus

The prototype brings together live image capture, human-background segmentation, image embeddings, change-based routing, and local vision-language model inference. Its purpose is to investigate selective processing for interactive perception.

Current scope

This is an exploratory implementation. Latency, model-call reduction, and missed changes have not yet been established by a controlled benchmark. A next step is to compare the gate with regular inference on the same recorded scenes while tracking responsiveness and missed events.
